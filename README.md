# 💅 Catálogo Digital de Serviços — Maria Julia Nail Designer

> Catálogo digital (página web) com os serviços, valores e formas de atendimento de uma nail designer, pensado para ser compartilhado por link no Instagram e no WhatsApp.

🔗 **Ver demonstração:** https://julio122dev.github.io/catalogo-maria-julia/

> ⚠️ **Esta é uma versão de demonstração para portfólio.** Telefone, endereço, localização e dados de pagamento foram removidos para proteger a privacidade da cliente. A versão oficial, com agendamento pelo WhatsApp, será publicada em hospedagem própria.

![Catálogo no celular](docs/screenshots/catalogo-mobile.png)

---

## ✨ Funcionalidades

- Serviços com foto, descrição, o que está incluso e preço
- Serviços complementares e formas de pagamento
- Botão de agendamento (na versão oficial, abre o WhatsApp com mensagem pronta)
- Link para o Instagram [@maajunails_](https://www.instagram.com/maajunails_/)
- Visual alinhado à identidade da marca (dourado), com tema claro e escuro automático
- Pensado primeiro para o celular, onde as clientes mais acessam
- Página única, leve e sem dependências

## 🛠️ Tecnologias

- HTML5
- CSS3 (layout responsivo, variáveis CSS, `prefers-color-scheme`)
- JavaScript puro
- Hospedado no **GitHub Pages**

## 🔒 Segurança e privacidade

- Todo conteúdo é inserido com `textContent` e escape de caracteres (proteção contra XSS)
- Links validados: só `http` e `https` são aceitos (bloqueia `javascript:`)
- Links externos com `rel="noopener noreferrer"`
- Versão pública sem dados pessoais: telefone, endereço, coordenadas e Pix removidos
- Metadados (EXIF) removidos das fotos
